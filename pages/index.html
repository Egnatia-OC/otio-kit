otio-kit · file-based editing engine

Timeline files are the automation surface Resolve Free didn't lose.

DaVinci Resolve 21.1 moved Python scripting to Studio. The Scripts menu loads nothing, the external socket refuses connections, and the console that remains is a sandboxed Lua REPL. What still works on Free is file import — and that is the surface this project builds on.

otio-kit compiles a small YAML brief into a standard OTIO timeline: cuts, a cross-dissolve, stills on upper tracks, markers, a music bed. Then you import it. No scripting bridge, no Studio licence, no Python inside Resolve. The output is a text file — diffable, versionable, revertable, readable before it touches a timeline.

Quickstart

pip install otio-kit          # Python 3.10+, pure Python, no Resolve needed to compile
otio-kit compile brief.yaml -o timeline.otio
otio-kit validate brief.yaml  # spec + media check, writes nothing

A brief is ~15 lines of YAML:

spec_version: 0
name: specimen-60
fps: 24
media:
  clip_a: media/clip_a_dnx.mov
  clip_b: media/clip_b_dnx.mov
  title:  media/title.png
timeline:
  video:
    - track: V1
      clips:
        - media: clip_a
          duration: 20.0
        - media: clip_b
          duration: 20.0
          transition_in: {type: dissolve, duration: 1.0}
    - track: V2
      clips:
        - media: title
          duration: 5.0
markers:
  - {time: 10.0, color: blue, name: beat-1}
$ otio-kit compile tests/golden/specimen60.yaml -o timeline.otio
compiled 'specimen-60': 5 clips, 3 tracks -> timeline.otio

What v0 covers — and what it refuses

InOut (loud error, not silent misinterpretation)
Timeline name/fps; sequential clips with frame-exact durations; cross-dissolve between adjacent clips; stills on upper tracks; 8 stock marker colours; media manifest with compile-time existence check Custom effect schemas (fatal to the importer); bare relative media URLs on Linux; gaps/offset placement; speed changes; effects, grades, Fusion comps; dissolves that don't fit their clips

Everything emitted is stock OTIO schema; project semantics ride in metadata. Durations are quantized to whole frames, so at 23.976 or 29.97 fps the total can differ from the nominal duration by a few frames — that is the model, documented, not drift to paper over.

Why a file, not an API call

Even if scripting returns to Free, the file approach stands on its own. A mutating API call is invisible until you look at the result; a timeline file can be reviewed, diffed, committed, and regenerated. The compiler is deterministic: the same brief produces the same bytes.
